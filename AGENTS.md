# Commits and PR titles

- Follow the [Scoped Commits](https://scopedcommits.com/) spec: `<scope>: <description>`.
  No Conventional Commits type prefix (no `feat:`/`fix:`/`chore:`).
- Scope is the subsystem touched (e.g. `board`, `cakeday`, `notifications`,
  `discord`, `api-catalog`, `readme-card`). Pick the most precise existing scope,
  or name a new one when a change introduces a genuinely self-contained subsystem.
- Apply this format to both commit subjects and PR titles.
